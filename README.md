# Kawaii-Survivor

Kawaii-Survivor是一款以可爱风格为主题的2D生存游戏。玩家需要在充满敌人的世界中生存，通过收集掉落物品、升级武器和提升角色能力来对抗越来越强大的敌人波次。

## 🎮 主要特点
- **经典的生存游戏玩法**
- **可爱的2D像素艺术风格**
- **多样化的武器系统**
- **角色升级和进度系统**
- **沉浸式的音效体验**
- **支持移动端触摸控制**

## 游戏特色
- **生存机制**：面对无尽的敌人波次，测试你的生存技能
- **武器系统**：多种武器可供选择和升级
- **角色进度**：通过游戏获得经验值和等级提升
- **掉落系统**：收集糖果、金币和宝藏来增强角色
- **商店系统**：使用收集的资源购买升级和新装备
- **移动控制**：内置摇杆控制，完美适配移动设备

## 技术栈
- **游戏引擎**：Unity 2023.2
- **渲染管线**：Universal Render Pipeline (URP)
- **平台**：2D游戏开发

### 主要依赖包
- **Unity URP 16.0.5**
- **LeanTween** (动画系统)
- **TextMesh Pro** (UI文本)
- **Mobile Joystick** (移动控制)
- **NaughtyAttributes** (开发工具)

## 游戏玩法
1. 移动：使用WASD键或屏幕摇杆控制角色移动
2. 战斗：角色会自动攻击附近的敌人
3. 收集：拾取掉落的物品来获得经验和资源
4. 升级：达到新等级时选择武器升级
5. 购买：在商店中使用金币购买增强道具
6. 生存：尽可能长时间地生存下去
## 开发说明

### 核心系统
- `GameManager`: 控制游戏状态和流程
- `Player`: 玩家角色控制和属性管理
- `EnemySystem`: 敌人生成和AI行为
- `WeaponSystem`: 武器机制和升级系统
- `UIManager`: 用户界面管理

### 编码规范
- 使用C#编写所有游戏逻辑
- 遵循Unity的命名约定
- 代码注释使用中文
- 使用`ScriptableObject`进行数据管理

### 使用的资源
- `BayatGames Free Platform Game Assets` - 角色和环境艺术资源
- `LeanTween` - 高效的动画系统
- `Mobile Joystick` - 移动设备控制方案
- `NaughtyAttributes` - 增强Inspector体验的开发工具
